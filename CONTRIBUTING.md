# Contributing to FinFlow Core

Thank you for your interest in contributing to **FinFlow Core**! This document outlines guidelines for issues, branching, and pull requests.

---

## 🛠️ Development Workflow

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/ronitgupta138/finflow-core.git
   cd finflow-core
   ```

2. **Branching Conventions**:
   - `feat/<feature-name>`: New features
   - `fix/<bug-name>`: Bug fixes
   - `docs/<doc-topic>`: Documentation updates
   - `test/<test-suite>`: Unit, integration, or concurrency test additions

3. **Running Tests**:
   Ensure all tests pass before submitting changes:
   ```bash
   mvn clean test
   ```

---

## 📝 Pull Request Guidelines

- **Commit Message Format**: Follow conventional commits (`feat:`, `fix:`, `docs:`, `test:`).
- **Verification**: Ensure all builds and tests pass cleanly.
